# OFDM Lab

Laboratoire scientifique Python de transmissions numériques en bande de base complexe,
niveau Licence avancée / Master. Développement progressif : bits, modulations, AWGN,
FFT/IFFT, OFDM, multitrajets, synchronisation puis interface interactive.

## Installation

Python 3.11 ou ultérieur :

```shell
python -m venv .venv
python -m pip install -e ".[dev]"
```

Utiliser le Python du venv : `.venv/Scripts/python.exe` sous Windows,
`.venv/bin/python` sous Linux/macOS. Voir CONTRIBUTING.md pour les conventions.
